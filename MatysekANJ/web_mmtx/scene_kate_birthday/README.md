# Kate - birthday

Urgentni samostatna MMTX scena pro narozeninove prani Katce.

- Vstup z hlavniho rozcesti: `../index.html?scene=intro4` -> tlacitko `Kate - birthday`.
- Scena: pet postav stoji na pasece a divaji se smerem k obrazovce.
- Dialog: kazda postava rekne anglicky predstaveni a prani, po kazde anglicke vete nasleduje cesky preklad.
- Dalsi tlacitko po dokonceni vede na `../scene02_sunnys_lost_nuts/`.

Texty byly proti hlasovemu zadani opraveny na spisovne anglicke tvary:

- `have`
- `health`
- `happiness`
- `a nice party`
- `dreams come true`
