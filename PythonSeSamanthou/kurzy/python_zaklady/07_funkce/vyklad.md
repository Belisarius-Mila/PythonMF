def definuje vlastní funkci: pojmenuje postup, který lze opakovaně zavolat. Samotná definice ještě nic nenakreslí.

Parametr x je vstup funkce. Při volání semafor(150) uvnitř funkce používáme x = 150. obdelnik(x1, y1, x2, y2, barva) dostane levý horní a pravý dolní roh. Tři volání kruh() přidají světla.

Tady svítí všechny barvy jako názorný obrázek. Řízení skutečné signalizace by byl další úkol.
