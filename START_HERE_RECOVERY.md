# START HERE: obnova Samanthy z iPhonu

Pokud původní Mac nejde zapnout nebo je ztracený, začni tady.

## Nejkratší cesta z iPhonu

Otevři v Safari nebo v GitHub aplikaci:

```text
https://github.com/Belisarius-Mila/PythonMF/blob/main/Samantha_Agent/RECOVERY_CARD_NEW_MAC.md
```

Zapamatovatelná cesta:

```text
GitHub -> Belisarius-Mila/PythonMF -> Samantha_Agent -> RECOVERY_CARD_NEW_MAC.md
```

## Co je důležité

- Kód a recovery karta jsou na GitHubu.
- Soukromá data jsou v externí recovery záloze `SamanthaSecureBackup`.
- Nekopíruj `~/.codex/auth.json`.
- Neposílej do chatu `.env`, hesla, tokeny ani app-specific passwords.
- Nic nemaž a nic nepřepisuj bez kontroly.

## Věta pro nového Codexe

```text
Jsem Míla a obnovuji Samanthu po ztrátě Macu. Pracuj česky.
```
