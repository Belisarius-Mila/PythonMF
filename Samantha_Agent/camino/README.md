V Human–Adam se projekt jmenuje **Camino** (`project-camino`). Nejdřív následuje
meziúkol podle Míly; při návratu začneme **C00 — read-only audit prostředí**.
C00, instalace, build, zkoušky telefonu i placené AI dosud neproběhly.
Rozbalené podklady v0.4 jsou verzované včetně manifestu. Původní ZIP je
zachovaný lokálně a ignorovaný Gitem; profilové workspaces přebírají dokumenty.
