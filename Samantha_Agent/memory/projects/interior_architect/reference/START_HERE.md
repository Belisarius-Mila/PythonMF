# Samantha SDK — Interior Architect 2.0

## Pokyn pro Codex
Pracuj v existujícím repozitáři Samantha SDK. Přečti SPECIFICATION.md, ARCHITECTURE.md, ROADMAP.md, TEST_PLAN.md a SCENE_MODEL.json. Nejprve respektuj AGENTS.md a lokální konvence. Proveď audit a následně skutečně implementuj etapu 1; nezůstávej u návrhu. Další etapy realizuj postupně po ověření předchozích.

Neprováděj placená API volání, neinstaluj velké modely, nemaž data ani nepřepisuj nesouvisející moduly. Před změnami zkontroluj git status; zachovej uživatelovy rozpracované změny a vytvoř bezpečnou pracovní větev, pokud to prostředí dovoluje. Při konfliktu či nevratné operaci požádej o rozhodnutí.

Po etapě reportuj změněné soubory, příkazy a výsledky testů, postup spuštění, omezení a další krok. Pokud repozitář není dostupný, vyžádej si jeho cestu.

OVERVIEW.html je samostatný grafický přehled pro člověka; Markdown a JSON jsou závazné zadání. Balíček neobsahuje implementaci ani ověřené výsledky testů.
